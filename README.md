# FitTrack Frontend

Frontend of the FitTrack fitness tracking app — built with React, Vite, TypeScript, and CSS Modules.

## Features

- JWT authentication
- Workout and exercise logging
- Body weight history tracking
- Modern, responsive UI

## Tech Stack

- React + Vite
- TypeScript
- CSS Modules
- Zustand
- React Router
- Chart.js

---

## Getting Started

```bash
npm install
npm run dev
```
